経路

機体は飛行計画の経路 (STAR / SID) を自動で飛びます。方位を指示するとレーダー誘導になり、経路上のFixを指示すると経路に戻ります。到着機は進入許可がないまま経路の終点に着くと、そこでホールディングします。経路にないFixを指示すると経路の付け替えになり、その最後のFixが新しい終点になります。

マウス

機体クリックで選択すると操作リングが出ます。内側の輪で方位 (Shiftで遠回り)、右の弧で高度、左の弧で速度をクリック。押したままなぞって離した所でも決まります。
選択中にFixクリックで直行
経路を一から組み直す: パネルの「組み直す」(または Shift+Fixクリック) → Fixを順にクリック → Enterで確定 / BSで1つ戻す / Escでやめる
右クリックでその方向へ旋回 / ドラッグで移動 / ホイールで拡大縮小

着陸

進入許可 (ILS) を出すと、経路の残りを飛んでから自分で最終進入コースに乗ります。レーダー誘導中なら今の方位のまま会合します。
許可がなくても、黄色い扇形の中で最終進入コースから±60°以内を向き、黄色い目盛りの高度(百ft)以下にすると自動でILSを捕捉します。

速度

10000ft未満は250kt以下。STARの速度制限 (STONE 250kt など) と待機中 (230kt以下) も自動で守ります。ILSに乗れるのは210kt以下。ILS上では S 160 などで5NMまでの速度を指示でき、その後は進入速度へ減速します (3NMで170ktを超えていると復行)。

機体一覧の ! マーク

! = 着陸・ハンドオフまでの指示が足りない (進入許可なし、最終進入の近くで210ktより速い、出口への経路や高度が未指示)。!! = このままだと2分以内に空域外へ出る。

上空通過機 (緑)

空域を横切るだけの機体 (中部マップ)。データブロック右下の出口 Fix を、表示の高度の範囲 (例 HEIAN090-130 = 9000〜13000ft) で通過させると次の管制へ引き継ぎ。

出発

T で離陸させ、データブロック右下の出口Fixを表示の高度以上で通過させるとハンドオフ成功です。

設定 (右上の ⚙)

コンピュータ管制 (AUTO) の切り替えと、高度の見せ方 (影で立体表示 / 選択機との高度差) を選べます。AUTO 中は上部に「AUTO 中」が出ます (押すと設定が開きます)。AUTO を使ったゲームはハイスコア対象外です。

得点

着陸・ハンドオフ +100、点線の標準経路に近く飛ばせると最大 +50。間隔欠如(3NM・1000ft未満) -30、空域逸脱 -100、衝突で終了。
